
# car-rental-angular

## Features

### Authorization & Authentication

* ✅ JWT authorization

* ✅ JWT interceptor set up

* ✅ Save JWT in local storage

* ✅ Route guards set up

### Cars & Rentals

* ✅ Get cars

* ✅ Rent an available car

* ✅ See your rentals in profile

### UI

* ✅ Interface built using Angular Material
